Como um job funciona

  • Bucket span — granularidade temporal (ex.: 15m)
  • Detector — função + campo: count, mean(latência), sum(bytes)
  • By/partition field — uma linha de base por entidade (host, url)
Assistentes: Single metric · Multi-metric · Population.

O ângulo ECK: papel ml

nodeSets:
  - name: default
    config:
      node.roles: ["master","data","ingest","ml"]
ML consome RAM além do heap da JVM. Em produção, um nodeSet dedicado a ML.

⚠️ Recursos no lab de 16 GB

  • Rode isolado (pare coletores e outros clusters)
  • Nó com mais RAM (manifest: 6Gi / heap 3G)
  • Datasets pequenos; ideal subir a VM para 32 GB

No laboratório

  • Ativar o trial + habilitar papel ml
  • Job single-metric (Count) sobre os web logs
  • Explorar no Anomaly Explorer (banda de normalidade + picos)
  • (opcional) multi-metric por geo.dest
