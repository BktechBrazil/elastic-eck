Kibana: Dashboards

De dados brutos a informação visual: Discover, Lens, dashboards interativos e gestão de saved objects.

Tudo começa no Data View

O Kibana não lê índices direto — lê Data Views: um "óculos" que aponta para índices por padrão de nome e define o campo de tempo.

Discover, Lens, dashboards e alertas: todos partem de um Data View.

Discover: investigar

Ver documentos brutos, filtrar por tempo, adicionar colunas e buscar com KQL:

customer_gender : "FEMALE" and taxful_total_price > 50
response.keyword : "404" and url : *login*
Discover investiga (um erro, um pico); dashboards acompanham.

Lens: visualizar

Editor drag-and-drop: arraste campos e ele sugere o gráfico. Por baixo é a dupla do Módulo 03: bucket + metric.

Dashboards: juntar tudo

  • Filtro de tempo global — muda o período de todos os painéis
  • Controls — menus/sliders que filtram tudo interativamente
  • Drill-down — clicar numa fatia filtra o painel
  • KQL + filtros na barra de busca do dashboard

Saved Objects = versionável

Data Views, visualizações e dashboards são Saved Objects, exportáveis em .ndjson.

  • Versionar o dashboard em Git
  • Promover dev → prod (Export/Import)
Mesma filosofia declarativa do curso, agora na camada visual.
