Elastic GenAI

Playground (RAG) e Agent Builder com LLM local — sem LocalAI, sem nuvem, tudo no seu ambiente.

A ideia: RAG

Pergunta▶ Elasticsearch recupera▶ injeta no prompt▶ LLM redige
O Elastic é o cérebro de recuperação; o LLM é o redator. Resposta fundamentada, com fontes.

Dois recursos built-in

Playground

Conversar com seus índices via RAG. Gera a query, injeta no LLM, mostra a query e o código Python.

Agent Builder

Agentes que respondem e agem: tools, skills, chat, MCP, workflows. Evolução GA do Playground.

LLM local via conector OpenAI

O Elastic conecta ao LLM por conector: OpenAI, Azure, Bedrock, Gemini — e LLMs locais compatíveis com OpenAI (Ollama, LM Studio, vLLM).

Em ECK self-managed não há "Elastic Managed LLM" → o LLM é sempre por conector. O local é o caminho natural.

Conector → Ollama

# Stack Management -> Connectors -> OpenAI
URL:   http://ollama.elastic.svc:11434/v1/chat/completions
model: llama3.2:1b
apiKey: ollama   # qualquer valor não-vazio

⚠️ Recursos no lab

  • Módulo mais pesado (LLM disputa RAM/CPU)
  • Modelo pequeno (1B/0.5B), nunca 7B+ em 16 GB
  • Rode isolado; ideal 32 GB. LLM no cluster ou na VM host

No laboratório

  • Subir Ollama (modelo pequeno) + trial + conector
  • Indexar base de conhecimento
  • Playground: conversar com os dados via RAG
  • Agent Builder: agente com tool de busca
